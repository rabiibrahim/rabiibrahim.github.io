# Rabi Ibrahim - Personal Portfolio

A modern, high-performance, responsive single-page personal portfolio website built with HTML, Tailwind CSS, and Vanilla JavaScript.

## 🚀 Overview

This portfolio showcases the professional experience, skills, and content creation work of Rabi Ibrahim, a Senior Staff Engineer and Content Creator. The design emphasizes a "dark mode" aesthetic with high-contrast accents, reflecting a bridge between academic theory and real-world systems.

## ✨ Features

- **Responsive Design**: Optimized for mobile, tablet, and desktop views.
- **Modern Animations**: 
  - Scroll-triggered reveal effects.
  - Animated blobs in the hero section.
  - Skill progress bars that animate on view.
- **Interactive Navigation**:
  - Sticky header with backdrop blur.
  - Smooth scrolling to sections.
  - Mobile hamburger menu.
  - "Back to Top" button.
- **Clean Codebase**: 
  - Semantic HTML5.
  - Tailwind CSS for styling (CDN based).
  - Vanilla JavaScript for lightweight interactions.

## 🛠️ Technologies

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Tailwind CSS (v3 via CDN)
- **Icons**: FontAwesome 6
- **Fonts**: Google Fonts (Inter, JetBrains Mono)

## 📦 Setup & Usage

No build process is required for this version.

1. Clone or download the repository.
2. Open `index.html` directly in your web browser.
